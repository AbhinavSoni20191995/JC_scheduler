End of semester / quarter

Run the tally to prepare the next round. It balances each track separately: for journal club and for progress report, it compares everyone's count to that track's average and adjusts. So someone who over-presented JC but under-presented progress gets fewer JC and more progress next round, independently. People above a track's average present less of it; people below (or who never presented it, or had to cancel) present more. This doesn't change the current schedule; it takes effect when you next generate or rebuild.

The tally window limits which sessions are counted — set it to the current semester's start and end so earlier rounds don't skew the balance. Leave both blank to count everything. After running: review the Priority column, adjust with + / − if needed, then use Rebuild future schedule to apply the new order.
